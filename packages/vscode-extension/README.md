# ArtBreak

**Your AI is working. Don’t fill the pause—look at a work of art.**

ArtBreak turns waiting into a brief moment with a painting. Install it and one
work opens right away. When Claude Code or Codex is working, ArtBreak brings
another work to your desktop when there is time to look.

No account. No API key. No separate app.

## Don’t fill the pause

A good work of art is a better place to put your attention than another tab.
ArtBreak gives it the screen for a moment, then lets you return when you are
ready.

Claude Code connects automatically for a `claude` session in a real terminal
(including VS Code's own integrated terminal, via **Claude Code: Open in
Terminal**) — Claude Code's built-in webview chat panel does not run the
lifecycle hooks ArtBreak needs, so sessions opened there won't trigger
artwork. Codex may ask for a one-time security approval before ArtBreak can
respond to Codex sessions.

## Availability and credits

This release supports Windows x64 and macOS on Apple Silicon; macOS Intel is
in progress. Artwork images and collection facts are provided by The
Metropolitan Museum of Art; each work links back to its source page.
